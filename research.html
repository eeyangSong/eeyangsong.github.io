LLM Capability Upgrades and User Demand: Engagement, Cannibalization, and Task Allocation (with Jingwei Dai and Beibei Li)

Current Stage: Manuscript in preparation for submission

We examine user engagement and task allocation around LLM capability upgrades, using conversation-level data to study demand for new models alongside continued use of existing models.

How Social Role Framing Shapes Users’ Interpretations of AI Memory References (with Yu Tong)

Current Stage: Data Collection

We examine how users interpret an AI’s references to past conversations, and how social role expectations shape these interpretations. The project explores implications for users’ perceptions and evaluations of the AI.
